# Startup CRM Lite

A simple and user-friendly Customer Relationship Management (CRM) application designed to help startups manage leads, track customer interactions, organize follow-ups, and monitor business performance.

## Live Demo

- **Frontend:** https://startup-crm-lite-zeta.vercel.app
- **Backend API:** https://startup-crm-lite-zcrl.onrender.com

## Features

- User registration and login
- Secure authentication
- Lead creation, viewing, updating, and management
- Lead status tracking
- Follow-up task management
- Dashboard with business statistics
- Search and filtering
- Responsive user interface
- Light and dark themes

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/navyasree-1234/startup-crm-lite.git
```

### 2. Open the project

```bash
cd startup-crm-lite
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
